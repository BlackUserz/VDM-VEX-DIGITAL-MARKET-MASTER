# VEX DIGITAL MARKET

Functional visual/testing prototype for VEX Digital Market.

## GitHub → Netlify
Upload the project to GitHub, connect it to Netlify, and use `.` as the publish directory. Do not upload `.env`. Put secrets in Netlify Environment Variables.

The prototype includes storefront, product catalog, cart, login-at-checkout demo, orders, settings/theme accent, help center, animated sections, product artwork, and an admin foundation. Payment, OAuth, Resend, database, real delivery, and KIE production integration require backend configuration.
