# VDM | VEX DIGITAL MARKET — Master Prototype

This ZIP implements the agreed VEX storefront prototype:
- VDM branding with black + gold identity
- left sidebar
- dashboard/storefront
- Flash Sale / Popular / New carousel sections
- one product card per product with package selection inside
- guest browsing and cart
- login only at checkout
- delivery email independent from account Gmail
- profile inside Settings
- automatic VIP Member / MEMBER labels
- real registration date display
- Preference for Dark/Light and theme accent
- theme accent drives UI glow/hover/lightning atmosphere
- orders/history and help center
- basic admin entry can be added as the backend phase
- .env.example + .gitignore + Netlify function skeleton

Important: Google OAuth, Resend, payment, database, automated delivery and KIE AI are intentionally backend placeholders until their real credentials/endpoints are configured. Do not put secrets in frontend files or GitHub.
